tinyapper

llms are too locked in... they require too much compute and everything is closed source and behind so much math... so i made one from scratch! yapperpedia is a demo for tinyapper, an open source llm project made using pytorch that is meant to be tinkered with. this demo uses a pretrained 50M parameter transformer to generate wikipedia-esque pages... mostly because i haven't tuned tinyapper to do anything else yet. have fun!

if anybody would like to tune tinyapper, optimize it (bugfixes particularly appreciated), or tinker around with tinyapper please head to the repo. this project was also submitted to hackclub's stardance, support on github and stardance is much appreciated <3
